# Steal an Alien - בוט דיסקורד ולוח בקרה

פרויקט אחד עם שלושה חלקים שעובדים יחד:

| תיקייה | מה זה | איפה זה רץ |
|---|---|---|
| `bot/` | הבוט של השרת: אוטו-אדמין, טיקטים, דרגות, פקודות צוות | אירוח לבוטים (Kerit) או המחשב |
| `web/` | לוח הבקרה: הכרזות, הבוט מדבר, הגדרות אוטו-אדמין, חברים, ערוצים | Vercel (חינם), או כל שרת Node |
| `shared/` | קוד שהבוט והאתר משתמשים בו שניהם (הגדרות, כללי AutoMod, הרשאות) | מועתק לשני הצדדים |

**מדריך התקנה מלא, צעד אחר צעד: [docs/HOSTING.md](docs/HOSTING.md)**

## מה הבוט עושה

- **אוטו-אדמין:** כללי AutoMod של Discord (ספאם, תיוגים, מילים, הזמנות, הונאות "Robux בחינם"), הגנה מפני הצפה והודעות חוזרות, הגנה מפשיטות, בדיקת גיל חשבון, שער אימות עם כפתור, נעילת חירום.
- **צוות:** `/warn` עם הסלמה אוטומטית, `/tempban`, `/timeout`, `/kick`, `/ban`, `/clear`, `/channel`, `/role`, `/voice`, `/lockdown`, יומן מלא ב-`mod-log`.
- **קהילה:** ברוכים הבאים, טיקטים עם תמלילים, דרגות XP עם 6 רולים, הצעות עם הצבעה.
- הרשימה המלאה: `/help`.

## מה לוח הבקרה עושה

כניסה עם Discord, רק למי שיש לו רול Moderator או Admin בשרת.
הכרזות עם תצוגה מקדימה חיה כמו בדיסקורד, הודעות בשם הבוט, עריכה ומחיקה של הודעות שהבוט שלח, יצירת ערוצים ורולים, כל הגדרות האוטו-אדמין, חיפוש חברים ואזהרות והשתקות והרחקות, טבלת דרגות, יומן של כל פעולה.

## הרצה על המחשב (לבדיקות)

```
cd bot && npm install && npm start        # הבוט (צריך bot/.env, יש תבנית ב-bot/.env.example)
cd web && npm start                       # האתר על http://localhost:3000 (צריך web/.env.local, תבנית ב-web/.env.example)
```

הקבצים `start-bot.bat` ו-`setup-server.bat` בשורש מפעילים את הבוט ובונים את השרת מחדש (מוחק הכל חוץ מ-Owner, מבקש אישור).

## בדיקות

```
npm test                  # הבוט, ובדיקה שהעותקים של shared/ מעודכנים
cd web && npm test        # האתר
```

אחרי שינוי ב-`shared/`: `npm run sync` כדי להעתיק לבוט ולאתר.

## מבנה

- `bot/src/blueprint.js` - מבנה השרת: רולים, דרגות, קטגוריות, ערוצים והרשאות.
- `bot/src/content.js` - הטקסטים של ההודעות הקבועות.
- `shared/settings.js` - כל הגדרות האוטו-אדמין וברירות המחדל שלהן.
- `web/lib/` - ה-API של האתר (פונקציה אחת ב-`web/api/[...path].js`), `web/public/` - הממשק.
- `docs/` - מדריך התקנה, מחקר, קובץ התקדמות.

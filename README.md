# Steal an Alien - Discord bot

בוט דיסקורד לשרת של המשחק **Steal an Alien**: בונה את השרת מאפס, מברך חברים חדשים, מנהל טיקטים, מערכת דרגות ומודרציה.

## הפעלה

1. `npm install` (פעם אחת).
2. קובץ `.env` (יש תבנית ב-`.env.example`):
   ```
   DISCORD_TOKEN=...
   GUILD_ID=...
   ```
3. **הפעלת הבוט:** לחיצה כפולה על `start-bot.bat` (או `npm start`). אם הבוט קורס הוא עולה מחדש אחרי 10 שניות.

## בניית השרת מחדש

`setup-server.bat` (או `npm run setup`). **מוחק את כל הערוצים והרולים חוץ מ-Owner ובונה הכל מחדש.** צריך להקליד את שם השרת לאישור.

- `npm run setup:dry` - מציג מה יימחק ומה ייווצר, בלי לשנות כלום.
- `npm run inspect` - מציג את מצב השרת (רולים, ערוצים, הרשאות הבוט).
- `npm run cleanup-roles` - מוחק שאריות של רולים ישנים (אחרי שהרול של הבוט הועלה מעליהם).

הבוט לא יכול למחוק רול שנמצא מעליו. לכן ב-Server Settings → Roles צריך לגרור את הרול של הבוט למעלה, מתחת ל-Owner.

## מה הבוט עושה

| תחום | פירוט |
|---|---|
| ברוכים הבאים | הודעה ב-`welcome` ורול Member לכל חבר חדש (דורש Server Members Intent) |
| טיקטים | כפתור ב-`create-ticket` פותח ערוץ פרטי. סגירה שומרת תמליל ב-`ticket-logs` |
| דרגות | XP על הודעות (15-25, פעם בדקה) ועל זמן בערוץ קולי (10 לדקה). 6 דרגות, רול אחד לכל חבר |
| הצעות | הבוט מוסיף 👍 👎 לכל הודעה ב-`suggestions` |
| מודרציה | `/clear` `/timeout` `/kick` `/ban` `/unban` `/slowmode`. כל פעולה נרשמת ב-`staff-chat` |
| צוות | `/announce` `/poll` `/ticket add/remove/close` `/xp` |

הרשימה המלאה: `/help`, והיא גם מתעדכנת לבד ב-`bot-commands` בכל הפעלה.

## קבצים חשובים

- `src/blueprint.js` - מבנה השרת: רולים, דרגות, קטגוריות, ערוצים והרשאות.
- `src/content.js` - הטקסטים של ההודעות (חוקים, ברוכים הבאים, טיקטים).
- `data/levels.json` - ה-XP של החברים. **לגבות.** באירוח צריך לכוון `DATA_DIR` לדיסק קבוע.
